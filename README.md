# Nabeel Zaidi - Modern Developer & Client Portfolio

A high-performance portfolio website built with **Next.js 15 (App Router)**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Live Demo & Featured Projects
- **Shajer Zaidi Brand Portfolio**: [Live Demo](https://shajer-updated-portfolio.vercel.app)
- **Dubai Real Estate CRM**: [Live Demo](https://dubai-real-estate-crm-nine.vercel.app)
- **Vigil AI SOC & Security Dashboard**: [Live Demo](https://frontend-one-navy-24.vercel.app)

## 🛠️ Tech Stack
- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React + Custom SVG Brand Icons
- **TypeScript**: Strict Type Checking

## 📦 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🚢 Deploy to Vercel (1-Click)
Push to GitHub and import the repository into [Vercel](https://vercel.com) for instant deployment with SSL and edge caching.
